# Projetos pendentes

## Quinto projeto da seção “Pesquisas e publicações científicas”

Ainda falta incluir um quinto projeto na rota `/banner1/`.

Dados necessários para a inclusão:

- título do projeto;
- nome do autor ou dos autores;
- link público do PDF no Google Drive, liberado para qualquer pessoa visualizar.

Quando esses dados estiverem disponíveis, adicionar um novo item ao painel correspondente em `src/content/site.json`, seguindo a estrutura dos quatro projetos existentes.
